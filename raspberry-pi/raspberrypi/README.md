# 树莓派外设脚本

目录由 `rassberyypi/` 改名而来（修正拼写）。这里是摄像头预览、拍照、录像和早期推理草稿，**不是座位数据上报入口**。上报请使用上一级的 `camera.py`。

文件名保持原样，避免把历史脚本伪装成新的正式接口。部分文件名和内容并不一致，下表按实际内容说明。

| 文件 | 内容 |
| --- | --- |
| `camera.py` | 打开摄像头并显示画面 |
| `cameratest.py` | 检查给定索引的摄像头能否打开 |
| `index.py` | 枚举可用摄像头索引 |
| `example.py` | 用指定索引拍一张照片 |
| `jiaoju.py` | 预览循环，调焦时看画面，按 `q` 退出 |
| `takeph.py` | 连续拍照并保存到文件夹 |
| `video.py` | 使用 `picamera` 录一段视频 |
| `takephotos.py` | 早期 YOLOv3（Darknet）单图推理，并不是拍照脚本 |
| `train.py` | ONNX Runtime 推理与画框，并不是训练入口 |
| `tep2.py` | 摄像头 + YOLO 计数草稿 |
| `tep3.py` | 空文件 |
| `test.py` | 多段摄像头检测草稿粘在同一个文件里 |

这些脚本依赖树莓派上的摄像头和本地权重，仓库不包含 `.pt` / `.onnx`。
